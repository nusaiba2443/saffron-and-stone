# Saffron & Stone — Restaurant Website

A responsive five-page restaurant concept website built with HTML, CSS and vanilla JavaScript.

## Pages
- `index.html` — Home, featured dishes, offer, gallery and testimonial
- `about.html` — Restaurant story and values
- `menu.html` — Filterable menu and interactive dish details
- `reservations.html` — Reservation form demo
- `contact.html` — Contact form demo and Dhaka map placeholder

## Features
- Responsive desktop/mobile navigation
- Persistent light/dark theme toggle
- Smooth scroll-reveal animations
- Interactive menu category filters
- Dish detail modal
- Gallery lightbox
- Reservation and contact form demo feedback
- Google Maps embed placeholder

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Important demo notes
Saffron & Stone is a fictional portfolio concept. Restaurant information, sample menu items, prices, hours, contact details and location are illustrative. The forms do not submit data, create bookings, or contact a business. The map is a Dhaka-area placeholder, not a verified venue address. Images and Google Fonts load from external services, so an internet connection is needed for those assets.
